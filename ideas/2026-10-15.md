### 1. Agent-Readiness Linter for Web Apps — [Passive]
- competence: unlabeled
- labeled_at: —

**Idea:** A CLI plus hosted GitHub Action that scans a web app's WebMCP/tool-calling surface and scores whether an AI agent can actually operate it, flagging vague tool schemas, non-actionable error messages, missing idempotency, and state changes an agent cannot observe, with a fix suggestion per finding.
**Leverages:** CoCircuit's agent-facing tool surface (actionable errors, viewport-follow for agent edits) and the checked-in rule-and-scope discipline from the Claude Code sub-agents work.
**One new thing to learn:** Parsing and statically analyzing WebMCP tool registrations, plus a headless-browser harness that drives them.
**Why it's worth it:** Teams are bolting agent interfaces onto apps with no way to check quality; a per-repo CI check sold as a subscription or one-time license is a recurring, low-maintenance product that few people are building yet.
