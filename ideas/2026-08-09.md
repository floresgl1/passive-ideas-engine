- competence: unlabeled
- labeled_at: —

**Idea:** Build a small Python library that runs multiple bounded LLM-agent tasks concurrently
under the same discipline finance_bot already applies to a single agent — step caps, retry
budgets, enumerated error categories — but adds real concurrency-safety (shared-state locking,
deterministic ordering of writes) carried over from the CSE4600 mutex work, for personal reuse

**Leverages:** LLM agent engineering's bounded-loop discipline (finance_bot) combined with

**One new thing to learn:** Carrying mutex/race-condition reasoning from C's threads into

**Why it's worth it:** Every future routine that needs more than one agent running at once needs
this exact safety layer; building it once, correctly, hardens a skill combination (concurrency +
agent discipline) that hasn't been tested together yet and that this very repo's own daily/weekly
routines are early customers for.
**First step today:** Write the single test that would have caught CSE4600's original race
condition, port it to a two-coroutine Python reproduction against a shared dict, and confirm it
fails before any locking is added.
