### 1. Netlist Solver API — [Leverage]
- competence: unlabeled
- labeled_at: —

**Idea:** Wrap the already-shipped MNA solver (`circuit-simulator`) behind a small hosted REST
API — POST a resistor/DC-source netlist, get back node voltages, source currents, and a clear
`SingularCircuitError` message — sold pay-per-solve or low-cost subscription to circuit-homework
helper sites, hobbyist EDA tool builders, and coursework auto-graders.
**Leverages:** The solver and its data model are real, tested, green code, not a concept to build
toward — paired with REST API design (Pydantic schemas, rate limiting) already proven twice

**One new thing to learn:** Designing a small, forgiving netlist input grammar (JSON or a simple
SPICE-like text format) so a stranger can describe a circuit without touching the Python
`components.py`/`circuit.py` objects directly.
**Why it's worth it:** Every prior circuit pitch had to invent the hard part first or defer to
"once the solver ships"; that gap just closed, so this is pure assembly of two already-proven
pieces rather than new invention.
**First step today:** Stand up one Flask/FastAPI route that accepts a hardcoded JSON circuit
description, calls `solver.py` directly, and returns node voltages as JSON — the whole product's
core loop in one file.
