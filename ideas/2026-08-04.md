**Idea:** Generalize finance_bot's bounded-agent architecture — step caps, retry budgets,
enumerated error categories, constrained output vocabulary, written v1 contract — into a

agents.

real differentiator (most agent scaffolds skip the retry/error-taxonomy discipline entirely).

finance_bot's agent module into a standalone file with zero finance_bot imports, and confirm it
