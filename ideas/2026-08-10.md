### 2. Statistical Significance Calculator for Indie Experimenters — [Passive]
- competence: unlabeled
- labeled_at: —

**Idea:** Build a small hosted calculator that takes a trial's raw counts (conversions, wins,
sample size) and returns the same judgment finance_bot already applies to trades — a CI lower
bound against a dynamically computed breakeven, not just a point estimate, plus a plain-English
"you don't have enough samples yet" flag — sold as a low-cost subscription to indie A/B testers,

**Leverages:** The graduated [strong] applied-statistics skill directly, for the first time as a
digest's core product rather than a supporting check inside another tool.
**One new thing to learn:** Generalizing the breakeven computation from "does this trade's edge

defines for their own use case.
**Why it's worth it:** The hard part — correctly reasoning about a confidence interval against a
moving breakeven instead of a naive point estimate — is already proven and running live; this
packages that judgment as a standalone tool, which is the one framing not yet tried across nine
prior digests.
**First step today:** Pull the CI-lower-bound-vs-breakeven function out of finance_bot's
confidence-interval module and rewrite its two inputs (trade P&L, transaction cost) as generic
named parameters — that's the calculator's entire core logic.

### 3. Grounded Support Agent Kit — [Experience]
- competence: unlabeled
- labeled_at: —

**Idea:** Build a small library that pairs finance_bot's bounded-agent discipline (step caps,
retry budgets, enumerated error categories) with visual-search-engine's embed/store/query loop,
generalized from image similarity to document-passage retrieval, so the agent must ground every

**Leverages:** Two already-shipped capabilities that have never been combined — bounded-agent

integration, which hardens a combination (bounded control flow + retrieval-grounded refusal) every

agent discipline with concurrency, not retrieval.
**First step today:** Take one finance_bot error category (e.g. "insufficient data") and redefine
its trigger condition as "no retrieved passage clears a cosine-similarity floor" — that single
rule is the refusal logic the rest of the kit hangs off of.
