### 2. Money-Invariant Property-Test Generator — [Passive]
- competence: unlabeled
- labeled_at: —

**Idea:** Package ledger-core's property-based zero-sum test and currency guard as a standalone
CLI that scans any Python codebase for money-shaped fields (amounts, balances, cents columns) and
generates property-based tests enforcing the same invariants already proven there — journals sum
to zero, no float ever touches a money field, mixed currencies never silently net — sold as a
one-time license to other developers building ledgers, invoicing, or payments code.
**Leverages:** Relational/double-entry data modeling `[strong]`, specifically the property-based
zero-sum test and currency guard already shipped and passing in ledger-core, generalized past the
one repo it currently lives in.
**One new thing to learn:** Static detection of "money-shaped" fields in an unfamiliar codebase
well enough to generate correct property-based tests automatically, rather than hand-writing them
against a schema already known in advance.
**Why it's worth it:** The invariants and the property-based test pattern are already proven
correct in ledger-core; the new work is narrowly the field-detection and generation layer, not the
underlying financial-correctness reasoning.
**First step today:** Point the CLI's first, hardcoded pass at ledger-core's own source, confirm it
can regenerate a test equivalent to the existing zero-sum property test from the schema alone.
