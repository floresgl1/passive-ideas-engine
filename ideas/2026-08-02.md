**Leverages:** stripe-reconciler's balanced-journal engine, tenant isolation, and reasoned security (CSRF, timing-safe auth, digest tokens) — the hard domain modeling (Suspense-account handling of unknowns) is already solved for one processor.

**Why now:** The billing/tenant/security scaffolding is sunk cost; this is schema + adapter work.
**First concrete step today:** Write the PayPal payout → journal-entry mapping spec (mirroring the existing Stripe balance-transaction → journal spec) and identify which fields route to Suspense by default.
